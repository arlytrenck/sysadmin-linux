# Sysadmin Linux — Runbooks & Scripts

This directory contains curated runbooks, scripts, and reference docs for Linux server administration. Fill in the runbooks and scripts with your environment-specific details and operational procedures.

Structure
- docs/runbooks/ — runbook templates (backup, ssh-key-audit, etc.)
- scripts/ — helper scripts and utilities (templates)
- .github/workflows/ — CI templates (ShellCheck)

How to use
1. Review runbooks in docs/runbooks/ before running scripts.
2. Review and test scripts in a safe environment before deploying to production.
3. Follow CONTRIBUTING.md for contribution guidelines.
